MORSE-CODE SIM

Same renderer as the panel on 170×320. Long-hold BOOT opens the action menu; incoming messages show a N NEW badge.

…

Keys: Space = BOOT (tap dot / hold dash / hold 1.5s menu), C = clear, R = receive. Display polls /api/frame.raw at ~30fps.

COMPOSE: type Morse. Long-hold opens the menu (SEND / CLEAR / READ n / CLOSE). Tap cycles, long-hold picks. SEND clears the buffer (simulates a send).
MESSAGE: tap = read this message (it is gone) + show next. Long-hold opens NEXT / CLOSE: tap cycles, long-hold picks. A read message is removed and the N NEW badge counts what is left. Each message has a unique #id.

Scenes: root, e-selected, hello, sos-help, mid-letter-s, wrapped, hold-dash, hold-menu, menu, badge, message, message-menu.
